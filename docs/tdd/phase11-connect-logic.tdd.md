# Phase 11, Workflow 11A Stage 2: connect-logic (TDD evidence)

Agent: `connect-logic`, beside `foundation-11a` (rule 23: it gates only `@openverify/core`). It owns `packages/core/src/connect/` except `categories.ts` (contracts-11a's, used and never edited), and its tests. Everything is pure: no route, repository or file of another package. Every timing has the load average (`/proc/loadavg`) beside it; none needs a lock (no Gradle, e2e or heavy call: core's suite is not one of rule 22's heavy calls).

`@openverify/core` cannot import `@openverify/contracts` or `@openverify/flow-spec` (both depend on it), so every function reads its inputs through structural types (`SharePolicyRules` is the stored policy's shape; a contracts `SharePolicy` is assignable to it) and the cross-checks against the contracts and flow-spec names are the Stage 3 callers' (listed in the handoff).
