## How the runs were made

Every Gradle call ran in the foreground under `flock -E 75 -w 240 /tmp/openverify-gradle.lock`.
The shared tree holds other agents' unfinished files, which sometimes do not compile, so my
red-green loop ran in a scratch worktree, `/tmp/driver-wt` (`git worktree add --detach`, rule 2),
into which I copied my own changed files; each checkpoint gate ran there on the committed `HEAD`
with nothing of mine left uncommitted. The worktree is removed at the end (rule 2).

`FakeFlowApi` (a secondary constructor takes the `flow` the tests already built; its transitions are
the server's to evaluate). Two other owners' fixture lines changed the same way, as borrowed edits
